# Keystream

An enjoyable typing visualizer tool that turns your keyboard into a piano.

## Features

-   **Interactive Visuals**: Watch bars or waves react to your keystrokes.
-   **Piano Sound**: Relaxing piano notes played for every key you press.
-   **Professional Theme**: Simple and Sleek dark design with customizable colors.
-   **Mute Toggle**: Toggle sound on/off.

## Installation

Ensure you have [Node.js](https://nodejs.org/) installed.

```bash
# Install dependencies
npm install
```

## Running the App

```bash
# Start the application
npm start
```
